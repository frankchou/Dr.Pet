# Phase 6 — Demo/Mock 飲食分析文案去醫療診斷語氣（Copywriter）

## 背景
Code review 指出 demo 飲食分析的「專家評語」（`expertComment`）及相關 mock 文案帶有**醫療診斷性語氣**，
與本系統「非醫療診斷、不取代獸醫」之合規定位不符。本次僅改寫 demo/mock 的**固定文案字串**，
不動程式邏輯、不動真實 AI 路徑（真實由 AI 生成，另靠 prompt 規範，不在本次範圍）。

## 改寫原則
- 去除「診斷／傷腎／恐／應（指令式）／安心餵食（過度保證）」等措辭。
- 改為「觀察到／偏高／可留意／建議留意／如有疑慮請諮詢獸醫師」等參考、輔助、提醒就醫語氣。
- 保留實用資訊與專業感，明確定位為「飲食參考」而非「醫療結論」。
- 字數與原本相當，未過度膨脹。

## 修改清單（檔案：`src/app/diet/page.tsx`，`MOCK_DIET_ANALYSIS`）

### 1. `expertComment`（L195）
- 前：`學理分析示磷值達臨界，應增水代謝。同步官方通報無警示批次，請安心餵食。`
- 後：`從學理觀察，磷值偏高、整體水分也略少，平時可留意補水。官方通報目前無相關警示批次。本評語僅供飲食參考，實際狀況請以獸醫師評估為準。`
- 理由：「達臨界／應增水代謝」為診斷指令式；「請安心餵食」過度保證。改為觀察＋可留意，並補上「以獸醫師評估為準」免責。

### 2. swap 建議 reason（L201）
- 前：`磷偏高恐傷腎`
- 後：`磷偏高，腎臟保健可留意`
- 理由：「恐傷腎」屬病症斷定，改為保健提醒。

### 3. swap 建議 reason（L204）
- 前：`鈉偏高腎臟負擔`
- 後：`鈉偏高，腎臟負擔建議留意`
- 理由：補上「建議留意」軟化為提醒語氣。

### 4. Tab「商品換掉」引導語（原 L1055）
- 前：`🔍 診斷：早、中、晚三餐成分中，以下商品建議更換，幫助毛孩遠離健康風險。`
- 後：`🔍 飲食參考：早、中、晚三餐成分中，以下商品可考慮更換，幫助毛孩降低潛在飲食風險。如有疑慮，建議諮詢獸醫師。`
- 理由：直接使用「診斷」一詞最敏感，改為「飲食參考」；「遠離健康風險」→「降低潛在飲食風險」，並補提醒就醫。
