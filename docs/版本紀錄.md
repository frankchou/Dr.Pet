### 同日 — 審查修正（code-reviewer + security-reviewer 各一輪）

兩位審查員合計提出 25 項（2 blocking / 2 high / 12 medium / 其餘 low）。已修正項目：

- **demo 登入口只靠裸 `DEMO_ENABLED`**（medium）→ 改為 `DEMO_ENABLED === 'true' && !isProductionEnv()`。Vercel 變數 scope 誤設成 All Environments 時，正式站原本會開出一個密碼公開於原始碼的登入口。
- **逃生門 `ALLOW_REMOTE_DB` 靜默永久生效**（medium）→ 啟用時每次連線 `console.warn`。
- **文件宣稱防呆「涵蓋所有 API / script / seed 路徑」與事實不符**（medium）→ `prisma.ts` 註解、README、系統機制三處改為據實描述「四道獨立守衛」表格。

### 23:59 — Phase 6-9 使用者選單「問題回報」+「評論／評分」

- **更新內容**：
  使用者選單（手機左上頭像選單／桌面左側欄）新增兩個入口——**「問題回報」**與**「評論／評分」**。

  **問題回報**：點開後是一個小視窗，可選填問題分類（功能異常 / Bug、操作建議、資料有誤、其他）並打字描述問題，送出後會存進系統、同時寄一封通知信到團隊信箱（`purepaw.notify@gmail.com`）。信件標題會依環境自動標 `[測試]` 或 `[正式]`。為避免誤觸重送，同一段內容 60 秒內重複送出只算一次；問題內容上限 2000 字。所有帳號（含 demo 體驗帳號）都是真的送出、真的存、真的寄信。寄信若失敗也不會害送出失敗（只在後台記錄）。
