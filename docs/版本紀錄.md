### 16:00 — 日誌頁全面改版（健康日誌 / 量測 / 用藥 / 美容記錄）

- **更新內容**：
  本次改版將 `/diary` 日誌頁從原本簡易記錄畫面，升級為涵蓋寵物全身健康狀態的完整每日健康追蹤中心。

  **新增資料庫模型（`prisma/schema.prisma`）**
  - `DailyHealthLog`：每日健康日誌主體，以 `@@unique([petId, date])` 確保每隻寵物每日只有一筆紀錄。涵蓋食慾、飲水量（ml）、飲水狀態、排便類型與細項、泌尿狀態、活力、情緒、皮毛狀況、眼耳狀況、牙齒狀況、消化、呼吸、神經、生殖（依性別記錄），以及每日例行清單、今日飲食狀態標籤、各餐狀態等欄位。多選欄位均以 JSON array string 儲存。
  - `MedicationRecord`：用藥與看診紀錄，記錄疫苗施打、驅蟲、處方用藥、看診備注（均為 JSON array），支援照片上傳及設定下次提醒日期。
  - `GroomingRecord`：洗澡美容紀錄，記錄自洗或外送美容兩種模式，四個進階療程各有獨立 boolean 欄位及使用產品名稱欄位，支援照片上傳及下次提醒日期。
  - `MeasurementRecord`：量測與追蹤紀錄，涵蓋體重（kg）、BCS 體態評分、呼吸心率（RRR）、血糖（空腹/飯後，mg/dL）、血壓（收縮壓/舒張壓）、體溫（量測方式 + 攝氏度數）。

  **新增 API Routes**
  - `GET/POST /api/daily-health-log`：讀取或建立/更新當日健康日誌（upsert，依 `@@unique[petId, date]` 避免重複建立）。
  - `GET/POST /api/medication-record`：讀取或新增用藥看診紀錄，GET 支援 `?recent=N` 參數取最近 N 筆。
  - `GET/POST /api/grooming-record`：讀取或新增洗澡美容紀錄。
  - `GET/POST /api/measurement-record`：讀取或新增量測追蹤紀錄。

  **新增 React 組件（`src/components/diary/`，共 20 個）**
  - 彈窗類（Modal）：`MedicationModal`（用藥看診快速輸入）、`GroomingModal`（洗澡美容快速輸入）、`MeasurementModal`（量測追蹤快速輸入），由 `DiaryTopBar` 的三個快捷按鈕觸發。
  - 每日健康卡片 Group 1：`AppetiteCard`（食慾）、`WaterCard`（飲水）、`StoolCard`（排便）、`UrineCard`（泌尿）、`VitalityCard`（活力）、`MoodCard`（情緒）。
  - 每日健康卡片 Group 2：`SkinHairCard`（皮毛）、`EyeEarCard`（眼耳）、`DentalCard`（牙齒）、`DigestionCard`（消化）、`RespiratoryCard`（呼吸）、`NeuroCard`（神經）、`ReproductiveCard`（生殖，依性別動態顯示）。
  - 頁面組件：`DailyChecklist`（每日例行清單）、`DietStatusCard`（今日飲食狀態，串接 MealPlan）、`DiaryCalendar`（月/週切換月曆）、`DiaryTopBar`（頂部工具列，含語音輸入按鈕 + 三個快捷 Modal 按鈕）。

  **日誌頁結構重新排列（`src/app/diary/page.tsx`）**
  - 上方新增區域（由上到下）：`DiaryTopBar` → `DiaryCalendar` → `DailyChecklist` → `DietStatusCard` → 13 張健康卡片（食慾→飲水→排便→泌尿→活力→情緒→皮毛→眼耳→牙齒→消化→呼吸→神經→生殖）。
  - 下方保留原有功能：AI 隨記 → 日常飲食紀錄 → 換食計畫。

  **自動儲存機制**：頁面載入時呼叫 `GET /api/daily-health-log` 取得當日紀錄並填入各卡片；使用者在任一健康卡片操作後，以 1000ms debounce 延遲自動呼叫 `POST /api/daily-health-log` 做 upsert，不需手動按儲存。
