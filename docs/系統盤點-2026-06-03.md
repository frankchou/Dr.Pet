## 二、AI 整合現況

### 已上線的 AI 功能（8 個 endpoint）

| API | 功能 | 呼叫位置 |
|-----|------|---------|
| `POST /api/chat` | AI 寵物諮詢對話 | `/nutritionist` |
| `POST /api/tasks` | 生成本週健康觀察計畫 | `/nutritionist` |
| `POST /api/instant-analyze` | 拍照成分即時判定（安全/謹慎/危險） | `/scan` |
| `POST /api/extract` | 成分標籤 OCR 萃取 | `/upload`、產品編輯 |
| `POST /api/diet-analysis` | 飲食配餐 AI 營養評分 | `/diet` |
| `POST /api/nutrition-ai` | AI 深度營養安全評估 | `/nutrition` |
| `POST /api/recommend` | 產品替代推薦 | `/nutrition`、換食計畫 |
| `GET /api/analysis` | 規則式成分知識庫比對（非 AI） | `/diet` Tab 4 |
